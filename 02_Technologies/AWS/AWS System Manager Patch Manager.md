## 1. 一言で言うと？
OSやアプリケーションへのパッチ適用プロセスを一元的に自動化する。

## 2. 特性
パッチベースライン(承認・承諾するパッチのルール)を定義し、メンテナンスウィンドウ(パッチ適用を実行する時間帯)や実行ターゲット(タグなど)をせて地することで、定期的なパッチ適用を大規模に適用できる。さらに、パッチコンプライアンスにより、各インスタンスの適用状況・不足パッチ・準拠状態を集約して確認でき、パッチステータスレポート要件も満たせる。
