## 1. 一言で言うと？
AWSリソースのインベントリ(存在するリソースとその設定状態)を継続的に記録し、リソースの構成スナップショットと変更履歴を時系列で保持できるサービス。

## 2. 特性
「いつ、どのリソースの、どの設定項目が、どのようにかわったか」を正確に追跡できる。さらにAWS Configルールを使用することで、許可されていないインスタンスタイプが起動されていないか、危険なポートが公開されていないかといったコンプライアンス違反を継続評価し、検知・通知できる。

## 3.他機能との対比
[[Croud Trail]]で操作ログを記録し、[[AWS Config]]でリソース設定の変更を追跡評価する。

| 機能 | **AWS CloudTrail** | **AWS Config** |
| :--- | :--- | :--- |
| **記録対象** | API コール（操作ログ） | リソースの構成情報 |
| **主な目的** | 「誰が」「いつ」「何をしたか」の追跡 | 「何が」「どのように変更されたか」の追跡 |
| **ユースケース** | 運用監査、セキュリティ分析、原因調査 | 構成監査、コンプライアンス評価、変更管理 |
| **評価機能** | なし（ログ分析は別サービスと連携） | Config ルールによる自動評価 |
