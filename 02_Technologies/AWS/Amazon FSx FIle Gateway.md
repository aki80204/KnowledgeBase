## 1. 一言で言うと？
[[AWS Storage Gateway]]の一種で、オンプレミス環境にゲートウェイを配置してローカルキャッシュを利用しながら、クラウド上の[[Amazon FSx for Windows File Server]]へ低レイテンシーアクセスを実現するハイブリッドアクセス向けの機能。

## 2. 特性
継続的にオンプレミスとクラウドをまたいでファイル共有を使い続ける構成に適している。
一括データ移行ツールではない。
