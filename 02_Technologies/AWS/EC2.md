## 1. 一言で言うと？
数分で起動・スケーリングが可能な、クラウド上の仮想サーバーコンピューティングリソース。

## 2. 特性（トレードオフの分析）
### 料金体系
| 購入オプション                        | 柔軟性（インスタンスタイプ / リージョン変更）   | 割引率  | 主なユースケース                                     |
| :----------------------------- | :------------------------- | :--: | :------------------------------------------- |
| **Compute Savings Plans**      | ◎ 高い（インスタンスタイプ / サイズ変更に強い） |  高   | インスタンスタイプやサイズを変更する可能性がある場合                   |
| **EC2 Instance Savings Plans** | △ 低い（インスタンスタイプ / リージョン固定）  | ◎ 最高 | 特定のインスタンスタイプを長期間使い続けることが確定している場合             |
| **スタンダードリザーブドインスタンス**          | × 最低（変更範囲が限定的）             | ◎ 最高 | インスタンス構成がほぼ固定されている場合                         |
| **コンバーティブルリザーブドインスタンス**        | ◯ 高い（条件付きで交換可）             |  高   | インスタンスタイプを変更する可能性があるが、EC2のみを利用する場合           |
| **ゾーンリザーブドインスタンス**             | △ 低い（インスタンスタイプ / AZ固定）     |  中   | 特定のAZでのキャパシティー予約を保証するもの。インスタンスタイプとサイズが固定される。 |
