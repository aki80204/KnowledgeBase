## 1. 一言で言うと？
セットアップ、運用、スケーリングが自動化された、マネージド型の関係データベースサービス（RDB）

## 2. 特性

| 機能               | **Amazon RDS マルチ AZ 配置** | **Amazon RDS リードレプリカ**          |
| :--------------- | :----------------------- | :------------------------------ |
| **主な目的**         | 高可用性（障害復旧）               | 読み取り性能のスケールアウト、DR               |
| **レプリケーション**     | 同期的                      | 非同期的                            |
| **フェイルオーバー**     | 自動                       | 手動（昇格が必要）                       |
| **スタンバイ / レプリカ** | 直接アクセス不可（フェイルオーバー時のみ使用）  | 独自の DNS エンドポイントを持ち、読み取りクエリに使用可能 |


## 3.他機能との対比
- EC2上にデータベースを構築する。
	- OSのパッチ適用、DBソフトウェアのインストールとアップデート、バックアップ設計、障害監視、レプリケーション管理などを行う必要が出てくる。マネージドサービスのRDSを選ぶのがベストプラクティス。
