## 1. 一言で言うと？
組織全体の[[Amazon S3]]ストレージの使用状況とアクティビティを可視化し、運用オーバーヘッドを最小限に抑えつつアクセスパターンを分析できる専用機能。
## 2. 特性
- バケット単位でリクエスト数、取得料、エラー傾向などのアクティビティ指標をダッシュボード上でドリルダウンしながら確認できる。

## 3. 他機能との対比
- AWSマネージメントコンソールのS3ダッシュボード
	- 個々のバケットの基本的な管理機能は提供するが、バケットを横断しての分析には向いていない。
- CloudWatch BucketSizeBitesメトリクス
	- バケットの合計サイズを示すもので、アクセスパターンは分析できない。
- AWS CloudTrail
	- S3のデータイベントを記録して分析することは可能だが、S3 Storage Lensと比較すると、設定・収集・分析の運用負荷が高く、ログ量に応じた追加コストも発生しやすい。
